Walkthrough of the user flow, the UI and what happens behind it.
Anyone opens the link. No sign-up.
A session and a 6-character code are created instantly. Enter a display name.
Copy the invite link or the code and send it to friends.
Friends type the code or open the link, pick a name, and join.
Up to 8 people per session. Everyone sees who is online.
Everyone chats in the same room. The bot sees who said what.
Before answering, the bot looks facts up in the NE knowledge base and live weather.
It balances both wishes and builds a shared plan that updates live for all.
Anyone can add a request; the bot reconciles and updates the plan.
Risky facts like permits carry a source, a verified date and a reminder to double-check.
Behind the scenes: one app container and one Postgres database.
One bot turn at a time per session, so a busy group still gets one coherent answer.
Please review the flow and settle these six questions. Then ADRs, then build.
